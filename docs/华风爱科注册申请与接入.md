## 换账号时怎样注册与申请

1. 进入 [华风爱科开放平台](https://platform.weathercn.com/)，使用自己的真实手机号注册。
2. 本人完成实名认证。姓名、身份证信息、人脸或验证码只在官方认证流程填写，不交给项目或助手保存。[官方隐私政策](https://platform.weathercn.com/apidoc/agreement-privacy.html)
3. 登录控制台，按页面流程领取标准能力 Key；如需创建应用，可填写：应用名称“风雨智游”，场景“智慧气象比赛中的文旅出行辅助决策”，平台“WebService API”。团队、学校、联系人和 IP 按实际情况填写。
4. 在应用/API 管理中核对有效期、500 次/天配额及已包含接口。已有标准权限时，无需重复申请长期逐时产品。
5. 在示例中心验证定位、72 小时逐时预报（`details=true&metric=true`）及天气预警；若返回 401/403，向平台提供不含 Key 的错误码、接口路径、调用时间和请求编号。
6. 若标准能力未覆盖所需字段或赛期，请在控制台申请权限/延期，或使用同目录的比赛试用申请草稿联系平台。

72 小时逐时预报列在标准能力中；120/240/360 小时需要另外开通。本项目先使用标准 72 小时，不请求这些进阶接口。[逐时接口说明](https://platform.weathercn.com/doc/api/hourly-forecast.html)

## 本机如何配置和验证

独立的本机配置文件为 `.env.weathercn.local`，优先于主 `.env` 加载；服务进程环境变量仍有最高优先级。文件已被 Git 忽略。

```dotenv
WEATHERCN_OPENAPI_KEY=填写你自己的标准OpenAPIKey
WEATHERCN_ENABLED=0
WEATHER_PROVIDER=auto
WEATHERCN_FORECAST_HOURS=72
WEATHERCN_DAILY_LIMIT=450
WEATHERCN_AUTH_MODE=query
```

在项目目录运行：

```powershell
.\.venv\Scripts\python.exe -X utf8 tools/check_weathercn.py --activate
```

脚本最多依次请求定位、预报和预警；验证明天完整 24 小时的关键字段、国内来源与预警权限。只有通过后才写入 `WEATHERCN_ENABLED=1`。随后重启 `serve.py`，在 `/api/travel/health` 查看 `weather_source=weathercn`，工作台应显示“华风爱科”。

鉴权兼容说明：官网概述和定位页推荐 `X-Gw-API-Key` 请求头，但本次该方式实测返回 401 `No API key found in request`。改用官网示例同时支持的 `apikey` 查询参数后返回 200。因此当前本机设置为 `query`；密钥仅由后端向官方 HTTPS 域名发送，浏览器不接触 Key。不打印完整外部请求 URL，也不向用户转发 requests 原始异常。若平台修复请求头支持，可改为 `header` 后重新验收。[定位接口及鉴权示例](https://platform.weathercn.com/doc/api/location-search.html)

## 项目中的实际行为

- 自动模式下优先使用已激活华风爱科；华风接口失效时明确报错，不偷偷混入另一个天气源。确需退回 Open-Meteo 时，显式将本机 `WEATHER_PROVIDER` 改为 `open-meteo` 并重启，页面会标明该来源。
- 工作台可选今天至后天，具体可用时段以真实预报覆盖为准。当前适配器没有历史产品权限，不再用该 Key 提供历史天气回放。
- 国内数据核对 `LocalSource.Id=7`；华风天气现象码单独解析，不当成 WMO 编码。降水概率不能替代雨强；风力等级不能冒充数值风速。未知字段保持缺失。
- 图表按实际小时定位；非全天或缺降水量时不显示虚假的全天零降水。问答页标明其统计的实际时段。
- 户外停留和转场检查关键数据与完整时间覆盖；缺失时拒绝相应可执行规划。天气预警接口不可用时暂停华风行程规划；与出行日期重叠的预警也会暂停自动规划，并提示查看官方与景区公告。这是保守规划规则，不是预警的业务分级认证。
- 不缓存或硬编码 Location Key，不存储完整定位响应。天气缓存保存归一化字段，遵守响应 Expires，有效时间最长 30 分钟。经纬度请求保留 3 位小数，使用 gzip，串行调用并节流。[调用规范](https://platform.weathercn.com/doc/dev-standard.html)
- 本机设置 450 次/天软预算，留出调试余量；平台控制台的实际用量为准。同 Key 的其他客户端、MCP 和手工调试可能共享额度。一次未命中天气缓存的请求通常包含 3 次接口调用，因此理论上约 150 次冷查询/天，不能把 500 次接口调用理解为 500 份完整行程。
- 缓存、配额文件、会话与密钥均排除在源码交付包之外。
