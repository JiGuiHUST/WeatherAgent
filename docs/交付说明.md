# 风雨智游 2.1 · 本地文旅应用交付

交付日期：2026-10-28。开发基线为原本地 `integrate` 分支，未覆盖另行克隆的 GitHub `main`，未推送仓库。

当前已优先接入华风爱科标准 OpenAPI，国内来源 `LocalSource.Id=7` 已通过真实检查。72 小时逐时预报与天气预警已验证，明天完整 24 小时关键字段齐全。当前配置可选择今天至后天；所选时段须处于实际返回范围，当前华风适配器不提供历史回放。注册、延期、权限、鉴权兼容及本机配置详见 [华风爱科注册申请与接入](华风爱科注册申请与接入.md)。之前的 Open-Meteo 联调记录是切换前的验收，不代表当前运行来源；以 `/api/travel/health` 和页面实时署名为准。

## 直接使用

打开 http://127.0.0.1:5000 。服务使用 Waitress，仅监听本机；关闭后双击上级目录的 `启动.bat`，或在项目目录运行：

```powershell
.\.venv\Scripts\python.exe serve.py
```

1. 选择日期、起点、出发/结束时间、交通方式和最多景点数。
2. 可勾选候选景点，也可交由系统自动挑选。未知或低可信度开放时间的景点仅供浏览。
3. 点击“生成我的行程”，查看到离时间、整段停留天气、适宜指数和导航。
4. 点击“更新预报并重排”，重新读取真实天气并比较行程变化。
5. “如果午后下雨”是明确标注的人工情景推演，不是真实预报。推演结果和真实行程分别标注。
6. “行程单”打开可打印页面，可通过浏览器打印为 PDF，也可下载包含来源证据的 JSON。
7. “旅行助手”已连接 DeepSeek，可解释当前行程，也可调用实际规划和景点查询工具。
8. 需要其他起点时，可点击地图位置并选择“从这里出发”；此处使用 WGS84 坐标。

界面支持桌面和窄屏。旧版目的地、多城天气路线、气象问答、中英研学和安全指南保留；武汉多城页的具体行程也调用受约束工具。其他城市的 AI 行程明确标注为未校验的灵感建议。

## 修复与实现

- 删除强制映射 2024 年的行为。主站与武汉工具使用统一真实天气源，历史资料保留原始日期。
- 当前预报、历史回放、人工模拟分开标注；真实天气失败时返回错误，不再合成气候曲线冒充预报。
- 风速、能见度直接取资料值；缺失值不伪造。AQI 本轮不提供。
- 景观“概率”改称规则适宜指数，不声称概率校准或模型预测准确率。
- 对完整游玩区间检查天气、闭馆、最晚入场、当日结束时间；修复闭馆后仍停留、跨越不适宜天气窗口的问题。
- 求解采用开放式行程，不强制隐含返程；支持不连续可行窗口、必去条件，并最终复核。
- 雷暴、较强降雨、强风、高温等按场景硬约束排除户外安排；关键字段缺失时不输出满分安全判断；危险转场会明确拒绝。
- 正式景点或类型模板缺失时不生成假真实行程。低可信度、未知开放时间不自动规划。
- 按官方资料更新湖北省博物馆、武汉博物馆、晴川阁、辛亥革命博物院、武汉科学技术馆、黄鹤楼的常规开放信息。仍需核实节假日和临时公告，系统不查询或代办门票预约。
- 路网增加缓存、请求节流、备用驾车服务；步行服务失败时可保留真实驾车矩阵。全部失败时明显标注直线估算。
- 新增交互地图、景点筛选/详情、逐时图表、行程解释、预报重排、模拟对照、打印/JSON导出和会话恢复。
- 模型凭据仅保存在被忽略的 `.env`；随机会话密钥、服务器端会话、同源写入检查；禁用调试模式。
- Leaflet、Bootstrap 固定版本资源已本地化。地图瓦片仍需联网；瓦片不可用时不阻止列表和行程功能。

真实联调脚本会调用联网服务和已配置模型，可能产生少量 API 用量；常规单元测试不调用模型。原始记录包含测试当时状态，不保证外部服务永久可用。

## 配置与维护

本机 `.env` 已按 DeepSeek 官方 OpenAI 兼容格式配置，服务地址 `https://api.deepseek.com`，模型 `deepseek-flash`；真实简短对话、行程解释、function-calling 均已验证。报告不包含密钥。

新机器安装：Python 3.10+，创建虚拟环境，`pip install -r requirements.txt`，从 `.env.example` 创建 `.env` 并填写自己的凭据，运行 `serve.py`。

- `.env`、`.session_secret`、`data/sessions/`、天气与路网缓存不应公开或随源码分享。
- 本机服务是个人/小团队的天气辅助规划工具。尚未实现账户体系、在线支付、门票库存、预约确认、商业地图实时路况或景区现场预警聚合。
- 开放时间资料按常规日程处理，法定节假日和临时安排优先；未知或低可信度景点暂不自动规划。
- 区域代表点预报并非每个景点的实测；行程适宜指数是规则评分。恶劣天气、突发封闭、拥堵等仍需出发前确认。
- 如需面向公网多人运营，需另外完成域名/HTTPS、用户鉴权、配额和服务容量部署；本次未发布公网服务。
